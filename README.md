# atividade-github-v2

Projeto de prática do fluxo de trabalho com Git e GitHub: criação de branch, commit, push e pull request.

## Funcionalidades

- Autenticação de usuários com geração de token JWT (`src/auth.js`)

## Como usar

No Git Bash: git clone https://github.com/vangobango/atividade-github.git

cd atividade-github

## Fluxo de contribuição

1. Crie uma branch a partir da `main`: `git checkout -b feature/nome-da-sua-feature`
2. Faça suas alterações e commit: `git commit -m "descrição da mudança"`
3. Envie para o GitHub: `git push origin feature/nome-da-sua-feature`
4. Abra um Pull Request para revisão
